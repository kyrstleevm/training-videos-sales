# training-videos-sales

A lightweight HTML5 video player designed for embedding into Notion training pages and LMS modules. It enforces video progress restrictions by preventing viewers from fast-forwarding past unwatched sections while retaining full support for play, pause, volume control, and backplay.

## ✨ Features

- **Anti-Forwarding Guardrail:** Automatically resets the seekbar back to the furthest timestamp watched if a user attempts to skip ahead.
- **Rewind & Re-watch:** Allows users to freely jump backward to review previously completed content.
- **Notion Responsive:** Optimized to sit cleanly inside a standard Notion `/embed` block.
- **Zero Cost:** Pure static HTML/JS—compatible with free hosting tiers on Cloudflare Pages, Vercel, or GitHub Pag
